# 字神经元 · 文字网络（char-neuron network）

**一个字 = 一个神经元**，让连接从语料里自己长出来——不写任何语言规则、不用反向传播、不用梯度。

这个库**只包含"文字网络"这一部分**的研究内容：机制、代码、报告、部分实验数据。
它是后续架构的**概念验证台**（把机制跑通、测出参数、暴露坑），不是最终模型。

---

## 一、这套机制的内核（8 条）

| # | 机制 | 一句话 | 实测结论 |
|---|---|---|---|
| 1 | **单元 + 有向连接** | 一个符号一个神经元；连接有方向、有上限、可增可减 | 20 亿字 → 8000 神经元、20.1 万条有向连接（0.31% 稠密度） |
| 2 | **凹形权重生长** | 共现越多，边际涨幅越小；只出现几次也能拿到可观权重 | `w = log(1+c/K) / log(1+C_ref/K)`，K=1、C_ref=10000 |
| 3 | **特异性闸门** | 抑制"的→X"这种到处都连的万金油连接 | PMI sigmoid：陡度 1.2、指数 1.4、下限 0.12 |
| 4 | **稀疏连接** | 每个单元只留最强的 top-k 条出边 | top_k=32 优于 64/128（128 会把噪声放进来） |
| 5 | **全局阈值整体调控** | 所有单元共用一个阈值；激活太少整体降、太多整体升 | 用"让目标个数的单元刚好越过阈值"的分位数反推，再平滑跟进（θ_lr=0.5）；目标 25 → 实测稳定在 20~30 个字 |
| 6 | **传播权重 ≠ 连接强度** | 连接强度是"学到的知识"；传播权重是"这次思考时它实际能推多少" | 见第二节；两层不分，思考立刻塌成字符噪声 |
| 7 | **实时学习（凹增量）** | 一起活跃就加强，增量同样越涨越难涨 | `Δw = η·a_i·a_j·(1-w/w_max)^pow`，η=0.004；蕉↔机 一次 20 步从 0 长到 0.092 |
| 8 | **增益控制** | 总激活越多，整体越难再推高（防正反馈爆炸） | `drive / (1+γ·Σa)`，γ=0.01 |

### 权重生长曲线（实测采用的那条）

| 共现次数 c | 1 | 3 | 10 | 30 | 100 | 300 | 1000 | 3000 | 10000 |
|---|---|---|---|---|---|---|---|---|---|
| 连接强度 w | 0.08 | 0.17 | 0.28 | 0.38 | 0.50 | 0.61 | 0.72 | 0.83 | 1.00 |

边际增益约 1/c：出现 3 次就有 0.17，出现 1000 次才 0.72 —— 冷门搭配不会因为"次数少"被永远压在阈值之下。

## 二、最重要的一条经验：两层权重

**连接强度 W（学到的知识）→ 传播权重 Ŵ（思考时的有效传导率）**，换算只做三件事：

1. **除以该单元的出边总强度**：出边多的常见单元被摊薄（"的"有 32 条几乎拉满的出边，"苹"只有 2 条）→ 冷门单元的专属连接才推得动搭档。
2. **除以该单元的入边总强度（有下限）**：谁都指向的万金油单元被摊薄。
3. **锐化 W^1.5**：不改排序，只把强连接与弱连接拉开量级。

对照实验（同一句话，只换传播方式）：

| 方案 | `苹果香蕉` 的思考内容 | 结论 |
|---|---|---|
| 连接强度 + 传播权重 | 榔 椿 蕉 薰 柚 梨 菇 炖 馅 熏 酥 芽 醇 脆 拌 醋 蒜 酸甜 辣 蜜 汁 葱 饼 酱 香 味 | 食物簇，可用 |
| 只有连接强度 | 蕉 Q Z 苹 Y － × J X j z U K q 3 5 W F H + V L R O N G | 塌成字符噪声 |
| 只有行归一化 | 和 蕉 蔬 苹 汁 脂 汤 地 酸 绿 茶 树 叶 洲 摄 他 肉 味 包 花 | 虚词混入（11/53） |

**迁移要点**：无论基本单元换成什么，只要一个单元的连接数差异很大，"连接强度"和"传播强度"就必须分开算，否则高频单元会淹没一切。

## 三、实测（20 亿字语料）

语料：悟道 + 中文维基 + SkyPile + chinese-fineweb-edu + 小说/金庸/诗词/古汉语 + 自抓网页新闻 → 清洗后 **19.7 亿字 / 322 万篇**。

**上下文决定思考方向**（同一前缀、不同后缀）：

| 激活 | 后续激活（去掉标点） | 语义 |
|---|---|---|
| 苹果手机 | 手 械 机 制 设 加 工 厂 房 续 改 内 | 制造/产品 |
| 苹果香蕉 | 蕉 葱 甜 浓 酸 盐 水 香 叶 绿 含 菜 切 树 皮 味 油 | 食物/植物 |
| 苹果价格 | 跌 幅 落 价 格 廉 涨 昂 钱 低 比 势 | 行情 |
| 苹果公司 | 司 公 拥 享 总 债 楼 园 厅 旗 | 公司实体 |
| 苹果发布会 | 会 发 布 士 莱 坞 现 显 | 发布会 |

两组思考的重合度（Jaccard）只有 **0.089** —— 上下文一换，思路就换，不是固定模板。

**整句激活**：
- `今天天气不错我想出去走走` → 趟 饭 吧 晚 错 早 吃 走 什 今 气 去 些 想 到 天 来 出 看 不 过 了 做
- `人工智能正在改变我们的生活方式` → 智 改 态 式 变 们 方 工 常 活 能 人 力 认 革 造

**冷门字不被压死**：频次仅 72 的 `劏` 能带出 `房`（劏房）、`㤭` 带出 `陈`（㤭陈如）；10 个样本里 3 个正确带出搭档，且线索字全部排在前列。

**新思想**：把语料里几乎不搭界的 `蕉` 和 `机` 一起激活，20 步后长出一条 0→0.092 的新连接；反复共现才会继续长（凹增量），不是一次性写死。

## 四、诚实记录的坑

1. **生僻字激活不是缺陷**。实测 `捂/拈/匣/呻/呤` 这些"生僻字"其实正好落在"手部动作""看病"的语义簇里。一度加"生僻目标抑制"压尾部噪声：噪声率 15%→5%，但冷门字带出搭档的成功率没有提升（"只压尾巴"变体反而 30/80 → 29/80）。**结论：不该靠压制生僻字来聚焦，该靠调小激活规模。**
2. **聚焦 vs 发散的硬取舍**。目标激活数 10~15 时输出最纯（如 `股票市场价格 → 涨 跌 盈 趋 估 幅 值 率`），超过 40 开始混入无关字。没有"既大又纯"的免费午餐。
3. **抑制神经元没有稳定收益**。开：虚词占比 0.17；关：0.13。机制本身工作正常（连接数 11.9 万），但在本任务里不划算 —— 建议保留为可开关项，别当核心。
4. **顺序信息只有相邻二元**。字序、长程依赖、句法都没进模型，所以思考结果必然是"模糊语义云"，不能成句。这是设计取舍，不是 bug。
5. **思考会漂移**。步数越多越容易从主题滑向通用字；靠"种子持续供能 + 小激活规模"能压住。

## 五、给后续模型的迁移清单

**直接照搬**
- 凹形权重生长（越涨越难涨）+ 权重上限
- 稀疏连接 + 特异性闸门（把"什么都能连"的单元压下去）
- 全局阈值整体调控（分位数反推 + 平滑跟进），绝不给单个单元固定阈值
- 连接强度 / 传播强度 两层分离（扇入扇出归一化）
- 实时学习用凹增量，且一次只能小步
- 增益控制（总量越大越难推高）

**改造后再用**
- 抑制神经元：做成可开关，先做 A/B 再决定留不留
- 特异性闸门的具体形式：PMI 依赖共现统计，若基本单元出现次数少，需要换更鲁棒的统计量
- 激活规模：按用途选（要"清楚"就 10~25，要"联想多"就 30~60）

**文字网络没有、后续要补**
- 时序/位置编码（现在只用相邻二元）
- 多单元绑定（把"苹+果"绑成一个概念，而不只是两个字互相点亮）
- 持久记忆与遗忘曲线（现在权重只增不减，没有衰减）
- 目标/反馈驱动的学习（现在只有无监督共现）

## 七、复现

```powershell
# 1) 清洗语料（各种格式统一成"一篇一行"）
python code\prepare_corpus.py --workers 5
# 2) 训练（默认参数即上面那组最优值）
python code\train.py --max-chars 2000000000 --min-freq 12 --max-vocab 8000 --name char_brain `
                      --save-counts models\counts_char_brain.npz
# 3) 单次思考
python code\think.py --model models\char_brain.npz --seeds 苹果手机 --steps 20
# 4) 完整实验 + 报告
python code\run_experiments.py --model models\char_brain.npz --out results\char_brain
python code\report.py --model models\char_brain.npz --results results\char_brain --out 字神经元网络_实验报告.md
# 5) 调参 / 消融
python code\sweep_all.py            # 20 组权重 × 140 组动力学 随机搜索
python code\ablation_minimal.py     # 最少机制对照
python code\ablation_prior.py       # 生僻目标抑制 消融
python code\demo_weight_layers.py   # 两层权重对照
```

> 语料需自行准备（本库不附带）。`code/tools/` 里的抓取与格式转换脚本未入库，如需可从原工作目录取。

## 一句话总结

**这套网络没有梯度、没有反向传播、没有语言规则**：它只靠"字与字在语料里共现"长连接、靠"整体阈值调控"决定此刻亮多少个字、靠"两层权重"让冷门搭配也推得动。
它的产出是**模糊的语义云**——不是句子；但它把"连接怎么长、阈值怎么调、权重怎么传导"这些机制跑通了，并留下了实测参数与五个坑。
